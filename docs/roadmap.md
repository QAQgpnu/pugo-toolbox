# Roadmap

## Next evidence, not feature count

1. Capture current-version screenshots and a 20–30 second demonstration GIF.
2. Complete a small iOS, Android, and HarmonyOS device matrix.
3. Turn repeated user feedback into reproducible issues before adding tools.
4. Add focused accessibility checks for font scaling, contrast, and touch targets.
5. Publish short technical notes for the local background-removal algorithm and privacy testing strategy.

The project does not plan to add login, advertising SDKs, cloud-only AI, or a backend merely to appear more complex.
